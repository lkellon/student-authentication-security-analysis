# Student Account Authentication Security Analysis

## Project Overview

This academic technical-writing project evaluates a university student account authentication process and recommends improvements that balance cybersecurity with usability. The analysis compares password-only authentication, SMS-based multifactor authentication, authenticator applications, and phishing-resistant methods such as passkeys and security keys.

The report draws on guidance from the National Institute of Standards and Technology (NIST) and the Cybersecurity and Infrastructure Security Agency (CISA).

## Key Recommendations

- Retain multifactor authentication for student accounts.
- Encourage long, unique passwords and the use of password managers.
- Promote authenticator applications over weaker SMS-based methods.
- Introduce phishing-resistant authentication, including passkeys or security keys, when supported.
- Improve enrollment and recovery instructions with numbered steps, screenshots, troubleshooting guidance, and account-recovery procedures.
- Explain the purpose of security controls so users understand why each step matters.
